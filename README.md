# Cubic Equation Solver using PyTorch

This project demonstrates solving a cubic equation of the form:

ax³ + bx² + cx + d = 0

using PyTorch with:

* Stochastic Gradient Descent (SGD)
* ReLU activation function

## Files Included

* `cubic_solver.ipynb` → Colab notebook implementation
* `course_completion.png` → Screenshot of 100% course completion

## Technologies Used

* Python
* PyTorch
